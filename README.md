I'm Hidayat Nur Wahid (Wahid), a full-stack web developer focused on building modern business applications with **Laravel** and **Next.js**. My work includes a multi-school management SaaS, an invoicing platform for freelancers and small businesses, and a coffee shop web application.

I enjoy turning real-world workflows into clean, usable interfaces styled with **Tailwind CSS**. Outside of application development, I set up and configure **home servers**, **Minecraft servers** and **GTA V (FiveM) servers**.
